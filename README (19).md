ERKLÄRUNG DER DREI DEKLINATIONSTYPEN:
================================================================================

A (schwache Deklination): 
  nach bestimmtem Artikel (der, den, dem, des) 
  → Adjektiv meist mit -en

B (gemischte Deklination): 
  nach unbestimmtem Artikel (ein, einen, einem, eines) 
  → Nominativ maskulin: -er, Nominativ/Akkusativ neutral: -es, sonst -en

C (starke Deklination): 
  ohne Artikel 
  → Adjektiv übernimmt die Artikelendung

HINWEIS: Im Plural gibt es keinen unbestimmten Artikel "ein", daher wird in 
Tabelle B der Negativartikel "keine" verwendet.
